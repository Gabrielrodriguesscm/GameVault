# 🎮 GameVault

O **GameVault** é uma plataforma web responsiva criada para exibição e descoberta de jogos digitais. O projeto foi desenvolvido do zero focando em um visual moderno (Dark Theme/Cyberpunk), layout fluido e boas práticas de estruturação HTML5 e estilização em CSS3.

---

## 🚀 Tecnologias Utilizadas

* **HTML5:** Estruturação semântica da aplicação.
* **CSS3:** Estilização, layout responsivo com **CSS Grid** e **Flexbox**, tipografia personalizada e efeitos de transição.
* **Google Fonts:** Utilização das fontes *Orbitron* e *Inter*.

---

## 🎨 Recursos da Interface

- [x] **Header Moderno:** Navegação limpa com elementos estilizados.
- [x] **Hero Banner Imersivo:** Seção de destaque com gradientes e chamadas de ação.
- [x] **Grid de Jogos Responsivo:** Exibição dos cards ajustando-se automaticamente ao tamanho da tela (`auto-fit` / `minmax`).
- [x] **Cards Estilizados:** Efeitos de hover e padronização visual das capas dos jogos.
